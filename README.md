# OxyFelt 조건 셋업 보고서 프로그램

브라우저(크롬·엣지)에서 링크로 여는 보고서 프로그램입니다. 설치나 로그인 없이 사용합니다.

- 시편 데이터(중량·두께) 입력 — 직접 입력, 엑셀 붙여넣기, 또는 시편 사진을 올려 AI로 자동 인식(Claude API 키 필요) 후 확인·정정 → 보고서 미리보기 → 이미지(PNG) 또는 PDF로 저장
- 처음 열면 보이는 값은 사용법 확인용 임의 예시 데이터입니다. [새로 시작]을 누르면 빈 양식이 됩니다.
- 입력한 데이터는 각자의 브라우저에 자동 저장됩니다 (다른 PC로 옮길 때는 '작업 파일 저장/열기' 사용)
- 관리자가 이 저장소에 새 버전을 올리면 사용자는 새로고침만 하면 자동으로 최신 버전을 씁니다. 페이지를 열어 둔 상태에서도 새 버전이 배포되면 상단에 안내가 표시됩니다.

## 파일
- `index.html` — 프로그램 본체
- `version.json` — 현재 배포 버전 (새 버전 안내에 사용)
